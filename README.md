# Minimal Audio Encoder
Reproducing something like the [Encodec](https://audiocraft.metademolab.com/encodec.html) model but as simpler as possible, just to generate listenable results. <br>
The idea is to use it as a didactic tool and to fork this repo to create a more complex version later. <br>

This project makes use of [Hydra](https://hydra.cc/) to manage configs. Greate Hydra tuturial: [link](https://youtu.be/tEsPyYnzt8s)
